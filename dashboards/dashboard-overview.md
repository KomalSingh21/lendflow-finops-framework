# FinOps Dashboard Overview

## Executive dashboard

Designed for CFO/CTO decisions:

- current monthly spend;
- budget versus actual;
- historical trend;
- cost per transaction/application;
- top cost drivers;
- month-over-month movement;
- forecast;
- savings target versus expected model; and
- commitment coverage.

## Engineering manager dashboard

Designed for engineering action:

- team/service spend;
- CPU and memory utilisation;
- right-sizing candidates;
- tag compliance;
- anomaly signals;
- RI/Savings Plans coverage; and
- Spot versus On-Demand suitability.

## Team dashboard

Designed for daily operational behaviour:

- service-level daily cost;
- deployment deltas;
- scaling events;
- idle-resource alerts;
- cost per endpoint; and
- trend/anomaly context.

The dashboard PNGs are illustrative mockups. The Draw.io files are the editable dashboard designs.
